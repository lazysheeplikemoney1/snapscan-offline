# UniApp 共享界面

2026-10-16：当前手机独立版由 `mobile/android-local/build_local.py` 将本目录生产编译为 H5，再与原生图像处理、OCR、存储和导出接口一同打包。运行于独立容器时，`utils/api.js` 强制使用本机接口，即使桥接初始化失败也不会退回电脑地址；首页隐藏后端设置，文件由原生系统接口保存、打开和分享。此版本无需启动 Python 服务。安装方法见 `docs/手机安装APK指引.md`。

本目录测试：`node --test mobile/uniapp/tests/*.test.cjs`（项目根目录）。本地接口、错误传播、扫描确认、校对、历史和导出均有回归测试。

## 旧局域网壳的导入与联调（保留供开发对照）

1. HBuilderX → 文件 → 导入 → 从本地目录导入 → 选 mobile/uniapp
2. APP 首页填写电脑当前 WLAN/热点地址（如 http://192.168.58.120:8000），点“保存地址”；地址保存在手机，下次打开仍生效。
3. 真机调试：手机连电脑热点 → 运行到手机 → 拍照扫描全链路
4. 打包APK：发行 → 原生App-云打包 → Android APK
5. 答辩：电脑开热点 + 后端 0.0.0.0:8000，手机开飞行模式+开WLAN连热点演示

首页“连通性检测”须显示模型已就绪及 `rec_head_v1`，识别结果页也显示实际模型版本。新模型运行于电脑后端，手机无需安装 PyTorch。源码中的默认地址仅用于首次打开；换网络后在首页修改即可。

旧版 APK 不含地址设置页，且固定使用 `192.168.56.120:8000`；要在当前网络使用上述设置，需要安装新构建版本。后端部署及回滚方法见 `backend/models/README.md`。

2026-10-15 文档工作台：结果页显示实际识别的扫描图，选择文字行可定位并逐行纠错，修改自动保留本地草稿；点保存或导出时回写后端。历史记录可重新打开校对。新扫描默认导出保留图像外观的可搜索 PDF，也可选纯文本 PDF；旧记录未保存图片，只能导出文本 PDF。纠错改变文字层，不改变扫描图中的字形。Excel 仍为 OCR 明细，未实现单元格恢复。

本地构建：`C:/pycharm/python.exe mobile/build_android_candidate.py --source-ready --variant document-workspace`（在项目根目录执行）。输出独立开发测试包，保留 Camera 注册修复并沿用已有开发签名。升级此客户端时也需重启新版后端，以迁移文档字段和启用纠错接口。真机拍照与运行验收需另行执行。

扫描成像版：拍照/选图先进入扫描预览，检查自动边界，必要时在原图拖动四角；选择自然彩色、清晰增强或黑白，应用后确认提取文字。可单独保存扫描图到相册。边界识别失败会提示手动选择或保留整图，处理图下载失败不会自动改用含背景原图。该版本使用 `--variant scan-imaging` 构建，需配合新版 `/api/scan/correct` 接口。
