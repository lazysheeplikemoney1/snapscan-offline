# 屏幕翻拍检测修复 · 0.2.1-local

> 公开版本说明：保留原评测结论与指标；原始图片、全文标注、安装包及详细运行证据保存在本地，本页已移除这些资料的下载链接。

## 失败原因与修复

用户在 iQOO Neo8 Pro / Android 15 上用相机拍摄屏幕中的小票。截图绿色四角是自动检测失败后的默认手调框，不能当成检测结果。旧版的固定中性纸色假设，以及纸张截断边必须紧贴照片边框的条件，分别在色偏和屏幕黑边下失效。Python 与 Java 主机运行均复现了失败；独立生成的不含界面覆盖的色偏、黑边变体也会失败。

新版保留原有完整文档检测和中性纸面检测，仅在它们均失败后增加自适应纸色候选：从当前图像估计较亮区域的主色，再校验纸面内部和两侧的真实边界。靠近照片边缘的宽暗带可作为可见内容截断的证据，但不外推照片之外的四角。完整白纸位于黑桌面的大面积正例仍走原检测路径。

自适应颜色遮罩只用于提议和验证边界，裁切保留四角内的全部源像素，再执行原有净白等增强。阴影和摩尔纹可能让遮罩漏掉票面局部，因此不按这种遮罩擦白正文。原色、净白、黑白、四角手调、相机/相册、确认后 OCR、校对、历史、PDF 和 Excel 流程保留。OCR 继续使用 `rec_head_v1`，本轮没有重新训练识别或语义分割模型。

## 仍需真机复测的范围

Android模拟器与 iQOO Neo8 Pro 是不同设备。尚未连接该手机运行新版本，也没有本次相机原图，不能给出该机扫描成功率、耗时、内存或相机兼容性的已验证结论。覆盖安装0.2.1后，应重新拍摄相同屏幕位置，核对自动四角与净白结果；若仍失败，保留相机原照片有助于定位，单独界面截图会损失输入信息。

严重卷曲、遮挡、暗色纸、纸与背景颜色接近时仍可能失败。当前按相连可见纸面估计范围，重叠的另一张纸可能一起保留；不恢复画外内容，也不自动补写模糊文字。本轮是有回归覆盖的检测修复，不代表通用语义分割、摩尔纹消除或OCR精度提升已经完成。
