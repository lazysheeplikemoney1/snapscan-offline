# 架构与离线声明（2026-10-16）

## 当前手机独立版

`SnapScan-offline-local.apk`：手机采集/显示 → 异步 Java 接口 → OpenCV Android + ONNX Runtime Android → 手机 SQLite / PDF / XLSX。界面、det/cls/rec_head_v1 模型、字典、字体和本地计算库均随 APK 内置。

没有 Python/FastAPI 服务器，没有监听端口；原后端的必要计算、存储和导出逻辑已移植为 App 进程内的 Java 模块。WebView 的虚拟 HTTPS 域名用于拦截本地文件。APK 不声明 INTERNET 权限，也没有模型下载或远程失败回退。

## 可以宣传
- 图像处理、OCR、历史搜索和导出均可在手机关闭 WiFi/移动数据后运行。
- 首次启动不下载模型，不依赖电脑；处理数据不经过互联网。
- Android 15 模拟器关闭网络的实际运行结果与 APK 静态核验单独留档。目标 iQOO 真机验收另行记录。

## 禁止宣传
- "表格识别恢复Excel"（实际是OCR结果导出XLSX）
- "手机OCR<800ms / CER4.3% / INT8体积-60%"（不能把规划或桌面结果当成该手机实测）
- "已训练语义分割模型 / 可恢复画外内容 / 自动分开所有重叠票据"（当前为边缘与纸面区域检测，有手动四角兜底）
- "手机端已实现FTS5、翻译、NCNN或表格结构恢复"（尚未实现）

## 实机断网验收

1. 安装独立 APK 后关闭 WiFi 和移动数据，冷启动 App，确认本机模型就绪。
2. 拍一张新照片，检查纸面裁切、三种增强和手动调整，并单独保存到相册。
3. 确认识别，校对后导出两种 PDF 和 Excel；用手机应用打开文件。
4. 关闭并重开 App，搜索并打开本机历史，核对图片和修订结果。
5. 记录手机型号、Android/WebView版本、输入大小、冷/热启动耗时、失败样例；真实计时前不写速度结论。

## 保留的旧局域网版本

`SnapScan-rec-head-v1-scan-imaging.apk` 等此前版本仍为手机采集 → WLAN → Windows FastAPI/OpenCV/RapidOCR。它们只是不依赖公网，不能脱离电脑运行。安装独立 APK 后不再使用该链路；两边历史数据库不会自动迁移。

构建工具/依赖首次获取可以联网；这与安装后的运行是否离线是两件事。主动通过系统分享发送文件是用户另行选择的系统行为，不属于 App 的扫描网络依赖。
