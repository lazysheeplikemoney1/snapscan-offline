# 电脑端断网验收清单（人工执行，Agent不碰物理网络）

前提：RapidOCR模型已缓存（backend/models/fp32/det_fp32.onnx, rec_fp32.onnx存在）。

1. 停止后端（关uvicorn）。
2. 断开Windows WAN/Internet（拔网线+关WLAN外网），保留本机127.0.0.1。
3. 不删除本地模型与依赖。
4. 冷启动：backend目录 python -m uvicorn app.main:app --host 127.0.0.1 --port 8000。
5. 用一张从未处理过的新本地图（建议现拍一张纸），依次执行：
   - GET /api/health
   - POST /api/scan/correct
   - POST /api/ocr/recognize
   - GET /api/history/list + search
   - POST /api/export/pdf + excel
6. 记录：是否200、有无traceback、OCR engine是否为rapidocr-onnxruntime。
7. 通过则在 docs/电脑端测试验收报告.md 第13节填"电脑断网冷启动PASS（人工）+日期"。
